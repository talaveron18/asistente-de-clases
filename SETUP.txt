ARGOS — INSTALACIÓN EN WINDOWS

USUARIO FINAL

1. Descarga ARGOS-Setup.exe desde la Release «latest» o desde el artefacto del workflow oficial.
2. Haz doble clic en ARGOS-Setup.exe.
3. Sigue el asistente de instalación.
4. Abre ARGOS desde el escritorio o el menú Inicio.

No necesitas instalar Python ni FFmpeg.

DESARROLLO DESDE EL REPOSITORIO

- Punto de entrada: argos_app.py
- Especificación única de PyInstaller: ARGOS.spec
- Instalador único: installer.iss
- Workflow único: .github/workflows/windows-installer.yml
- Resultado esperado: release\ARGOS-Setup.exe

El instalador solo debe darse por validado cuando GitHub Actions termine correctamente y se pruebe en un Windows limpio.
